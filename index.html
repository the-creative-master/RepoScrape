Quick add
How it is used: each query is paged through the repository search API, so topic:games with 5 pages means up to 500 repos considered. The API caps any single query at 1,000 results, which is why several narrow queries beat one broad one.

Files & archives

Scraped files are written straight to disk (OPFS / IndexedDB), not held in RAM, and streamed out one file at a time when packing.

Streaming options
When enabled with Max size per part > 0, each filled part downloads immediately during the scrape and deletes its temporary disk cache so you can scrape 10+ GB even with low disk space.
